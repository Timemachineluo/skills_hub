## 模板使用规则

- 章节顺序与编号固定，不得增删顶层章节。
- 表格列固定，行数按实际内容填充。
- P0/P1/P2 定义：P0 = 主流程正常场景；P1 = 重要分支与高频异常；P2 = 低概率异常与边界组合。
- 若功能点数量多（>15 个），第 5 章按功能点分小节呈现；若单表过长，可拆分为多个 Markdown 文件并在此文档中列出索引，但顶层结构不变。
- **本文档是编写 testcase.c 用例代码的直接参照物，必须先于代码生成**：后续编码阶段以本文档为唯一依据，逐条实现用例表中的 TC，测试数据与预期结果原样落入代码。最终交付物是项目 `testcase/testcase.c` 中的新增 C 测试用例代码：格式（测试框架、断言方式、函数命名、注册入口）严格遵循 `testcase/` 路径下 demo 的约定，追加写入、不改动既有内容，每条用例函数名含用例编号以保证与本文档可追溯。本文档随最终交付附上。
