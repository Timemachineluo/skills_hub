## 模板使用规则

- 章节顺序与编号固定，不得增删顶层章节。
- 表格列固定，行数按实际内容填充。
- P0/P1/P2 定义：P0 = 主流程正常场景；P1 = 重要分支与高频异常；P2 = 低概率异常与边界组合。
- 若功能点数量多（>15 个），第 5 章按功能点分小节呈现；若单表过长，可拆分为多个 Markdown 文件并在此文档中列出索引，但顶层结构不变。
- **本文档必须先于 testcase.c 生成，并作为编码的唯一依据**：编码阶段逐条实现本表的 TC，测试数据与预期结果原样落码；用例编号写入函数名以保证可追溯。本档随最终交付附上。
