# 通用异常场景清单（错误推测法素材）

test-design skill 在 Step 2 生成异常场景与 Step 3 覆盖率自检时，必须对本清单逐项核对。对每个功能点：适用项生成异常场景；不适用项无需生成场景，但应能说明不适用原因。

## 1. 输入类异常

- [ ] 空输入：必填项为空、空字符串、纯空格
- [ ] 格式错误：类型不符（数字位输入字母）、格式不符（邮箱/手机号/日期格式）
- [ ] 长度异常：超长（含极限长度+1）、过短（低于最小值-1）、0 长度
- [ ] 特殊字符：中文/英文混合、emoji、SQL 注入片段（' or 1=1）、XSS 片段（`<script>`）、HTML 标签、引号、反斜杠、通配符
- [ ] 非法值：负数、0（若 0 非法）、超大数值（溢出）、小数精度（金额 0.005）、科学计数法
- [ ] 复制粘贴内容：带隐藏字符（\t、\r\n、零宽字符）、带格式文本

## 2. 操作类异常

- [ ] 重复操作：重复提交、双击按钮、并发重复请求
- [ ] 中断操作：流程进行中取消、关闭页面/杀进程后恢复、刷新/回退后重试
- [ ] 越权操作：无权限用户访问、修改他人数据、绕过前端直接调接口
- [ ] 顺序颠倒：跳过前置步骤直接执行后续操作
- [ ] 超时行为：操作超时后的提示与状态、会话过期后提交

## 3. 数据类异常

- [ ] 数据不存在：查询/操作不存在的记录、已删除的数据
- [ ] 数据重复：唯一性字段填入重复值
- [ ] 数据依赖缺失：引用的关联数据被删除或禁用
- [ ] 边界数据量：列表为空、单条、恰好一页、超大数据量分页
- [ ] 数据状态不符：对处于错误状态的数据执行操作（如已取消订单再支付）

## 4. 环境与接口类异常（功能测试范围内适用时）

- [ ] 网络异常：请求中断、弱网、返回格式错误
- [ ] 依赖服务失败：下游接口报错/超时时的降级与提示
- [ ] 并发冲突：多用户同时编辑同一数据、库存并发扣减

## 使用说明

- 本清单是兜底手段：先用等价类/边界值/判定表/场景法/状态迁移生成异常场景，再用本清单查漏。
- 项是否适用取决于功能设计文档描述的功能性质（如纯 UI 展示功能不适用接口类）。
- 清单项生成的场景，若规格与 demo 均未定义预期行为，按合理假设给出预期结果并标注「基于假设」，登记到测试设计文档「假设登记」章节。
