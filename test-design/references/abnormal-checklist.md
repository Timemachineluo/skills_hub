# 通用异常场景清单（错误推测法素材）

test-design skill 在 Step 2 生成功能异常场景、Step 4 覆盖率自检时逐项核对。适用项生成场景；不适用项须能说明原因。

## 1. 输入类异常

- [ ] 空输入：必填项为空、空字符串、纯空格
- [ ] 格式错误：类型不符、格式不符（日期/编号/枚举外的取值）
- [ ] 长度异常：超长（含极限长度+1）、过短（低于最小值-1）、0 长度
- [ ] 特殊字符：中文等多字节字符、转义字符、引号、反斜杠、通配符、控制字符
- [ ] 非法值：负数、0（若 0 非法）、超大数值、小数精度、科学计数法

## 2. 操作类异常

- [ ] 重复操作：重复提交、连续触发同一操作
- [ ] 中断与恢复：流程中途终止后重试、状态能否恢复
- [ ] 越权与身份：无权限身份执行、绕过前置校验直接调用接口
- [ ] 超时行为：操作超时后的提示与状态、会话/凭据过期后提交

## 3. 数据类异常

- [ ] 数据不存在：操作不存在的记录、已被删除的数据
- [ ] 数据重复：唯一性约束字段填入重复值
- [ ] 数据依赖缺失：引用的关联数据被删除或禁用
- [ ] 数据量边界：空集合、单条、恰好满容量、超容量
- [ ] 数据状态不符：对处于错误状态的数据执行操作

## 使用说明

- 本清单是兜底手段：先用等价类/边界值/判定表/场景法/状态迁移生成异常场景，再用本清单查漏。
- **与 `bug-category-checklists.md` 的分工**：本清单聚焦功能视角的异常输入与数据；重复调用、资源泄漏、并发、崩溃类异常归可靠性清单，越界/溢出/注入等攻击手法归安全清单——两份清单都须逐项核对。
- 顺序颠倒/跳步、旅程中断重启等跨步骤序列，由 design-methods.md 第 10 节六种组合模式覆盖，此处不再重复。
- 清单项若规格与 demo 均未定义预期行为，按合理假设给出并标注「基于假设」，登记到「假设登记」。
